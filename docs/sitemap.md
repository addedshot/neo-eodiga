# 너어디가 사이트맵

2026-11-10 사용자와 확정한 메뉴 구성이다. 상세 기능은 단계별 Plan에서 정한다.

## 사이트 방향
- (2026-11-13 사용자) 이용자가 아무 정보 없이 여행을 가고 싶을 때 계획을 대신 세워 주는 사이트다. 집에서 출발해 여행을 즐기고 집으로 돌아오기까지 모든 정보를 제공해서, 여행 정보를 모으는 스트레스를 대신 덜어 주는 것이 목적이다.
- 사이트의 중심은 **여행추천**이다. 누구와, 언제 가는지 고르면 실제 기록을 바탕으로 추천 코스를 보여준다.
- 추천 코스 중 예약이 필요한 곳은 예약 링크로 안내한다.
- 테스트 단계에서는 운영자 혼자 쓰는 개인 사이트라서 로그인과 회원 기능을 만들지 않는다.

## 메뉴 구조
표시는 ✅ 이미 있음, 🆕 새로 만들 메뉴다.

```
너어디가  /                               ✅ 메인 (여행추천으로 들어가는 첫 화면)
│
├─ 여행추천  /recommend                   🆕 사이트의 중심 (지금은 준비 중 페이지)
│   ├─ 조건 고르기 (누구와, 언제)
│   ├─ 추천 코스 목록
│   └─ 코스 상세  /recommend/[slug]        방문 순서, 장소, 예약 링크
│
├─ 여행후기  /reviews                     ✅ 코스의 근거가 되는 실제 기록
│   └─ 후기 상세  /reviews/[slug]          ✅
│
├─ 지역축제  /festivals                  ✅ 달력·목록 (전국, 한국관광공사 자료, 주 1회 자동 갱신)
│   └─ 축제 포스트  /festivals/[id]          ✅ 한눈에 보기, 예약·신청 안내, 예상 날씨, 근처 숙소, 주변 상설 행사. 끝난 지 3일 뒤 사라짐
│
├─ 여행지도  /map                         🆕 운영자가 다녀온 시군구 기록, 로그인 없음 (지금은 준비 중 페이지)
│
├─ 공지사항  /notices                     ✅
│   └─ 공지 상세  /notices/[slug]          ✅
│
└─ 이용 안내  /guide                      ✅
    └─ 안내 상세  /guide/[slug]            ✅
```

## 화면에서의 위치
| 위치 | 메뉴 |
|---|---|
| 헤더 주 메뉴 | 지역축제 · 여행후기 · 여행추천 · 여행지도 (사용자가 정한 순서) |
| 메인 | 여행추천 시작, 공지사항과 지역축제(반씩), 이용 안내 바로가기, 최근 후기 |
| 푸터 | 공지사항 · 이용 안내 |

아직 기능이 없는 메뉴(여행추천, 여행지도)는 "준비 중이에요" 페이지로 연결한다. 이 페이지는 검색엔진에 노출하지 않고(noindex) sitemap에도 넣지 않는다. 기능을 만들면 준비 중 페이지를 바꾼다.

## 만들지 않는 것
로그인, 회원가입, 내 정보, 이용약관과 개인정보처리방침, 회원 후기 쓰기, 댓글, 도움 됐어요, 신고, 관리자 대시보드.
