# 너어디가 사이트맵

2026-11-10 사용자와 확정한 메뉴 구성이다. 상세 기능은 단계별 Plan에서 정한다.

## 사이트 방향
- 사이트의 중심은 **여행추천**이다. 누구와, 언제 가는지 고르면 실제 기록을 바탕으로 추천 코스를 보여준다.
- 추천 코스 중 예약이 필요한 곳은 예약 링크로 안내한다.
- 테스트 단계에서는 운영자 혼자 쓰는 개인 사이트라서 로그인과 회원 기능을 만들지 않는다.

## 메뉴 구조
표시는 ✅ 이미 있음, 🆕 새로 만들 메뉴다.

```
너어디가  /                               ✅ 메인 (여행추천으로 들어가는 첫 화면)
│
├─ 여행추천  /recommend                   🆕 사이트의 중심
│   ├─ 조건 고르기 (누구와, 언제)
│   ├─ 추천 코스 목록
│   └─ 코스 상세  /recommend/[slug]        방문 순서, 장소, 예약 링크
│
├─ 여행후기  /reviews                     ✅ 코스의 근거가 되는 실제 기록
│   └─ 후기 상세  /reviews/[slug]          ✅
│
├─ 지역별 축제  /festivals                🆕
│   ├─ 달력·목록
│   └─ 축제 상세  /festivals/[slug]
│
├─ 나의 여행지도  /map                    🆕 운영자가 다녀온 시군구 기록 (로그인 없음)
│
├─ 공지사항  /notices                     ✅
│   └─ 공지 상세  /notices/[slug]          ✅
│
└─ 이용 안내  /guide                      ✅
    └─ 안내 상세  /guide/[slug]            ✅
```

## 화면에서의 위치
| 위치 | 메뉴 |
|---|---|
| 헤더 주 메뉴 | 여행추천 · 여행후기 · 지역별 축제 · 나의 여행지도 (만들어진 것만 넣는다) |
| 메인 | 여행추천 시작, 최근 후기, 공지사항, 이용 안내 바로가기 |
| 푸터 | 공지사항 · 이용 안내 |

공지사항과 이용 안내는 여행추천을 헤더에 넣을 때 헤더에서 빼고 메인과 푸터로 옮긴다.

## 만들지 않는 것
로그인, 회원가입, 내 정보, 이용약관과 개인정보처리방침, 회원 후기 쓰기, 댓글, 도움 됐어요, 신고, 관리자 대시보드.
